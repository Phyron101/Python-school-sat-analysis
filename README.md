# NYC School SAT Analysis

## Overview

This project analyses SAT performance across New York City public schools using Python and pandas.

The analysis focuses on identifying schools with strong mathematics performance, calculating total SAT scores, and exploring differences in performance across schools.

## Tools & Technologies

* Python
* Pandas
* NumPy

## Analysis

The project includes:

* Importing and exploring a CSV dataset
* Filtering schools based on mathematics scores
* Calculating total SAT scores
* Identifying the top 10 schools by total SAT score
* Calculating statistical measures
* Exploring SAT performance by borough

## Files

* schools.ipynb — Python analysis and findings
* schools.csv — Dataset used for the analysis
* schoolbus.jpg — Supporting project image, where applicable

## Key Skills Demonstrated

Python data analysis, data cleaning, filtering, sorting, aggregation, and exploratory data analysis.
